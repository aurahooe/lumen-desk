# Lumen Desk

A quiet editorial board. Hourly dispatch, private desks, public wall.

## Stack

- Next.js 14 (App Router)
- Client-side auth (PBKDF2) + localStorage notes
- Hourly dispatch via automation → `data/dispatch.json`

## Local

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy

Import this repo in Vercel (framework: Next.js). Pushes to `main` deploy automatically.
